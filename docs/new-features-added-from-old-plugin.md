# Spot Award Plugin New Features Added

This document lists only the features that were newly added in the current plugin when compared with the older Spot Award plugin.

Baseline compared:
- Old plugin: `C:\Users\Admin\Desktop\Spotaward\old spotaward\moodle-local_spotaward`
- Current plugin: `C:\Users\Admin\Pictures\MoodleWindowsInstaller-latest-500\server\moodle\local\spotaward`

## Main newly added features

- Admin dashboard for records shared to Admin
- student count display in Admin dashboard records
- reassignment workflow and reassignment form
- nominator submission history view
- nominator access to student details
- nomination suggestions aligned with gradebook-category logic
- audit log page with filtering and delete actions
- configurable email template management from plugin UI
- configurable Zoho Cliq template management from plugin UI
- Moodle record link support in workflow notifications
- dynamic gradebook-category based report logic
- CSV student detail export
- PDF student detail export
- PR download flow
- share-to-admin workflow
- admin certificate bundle download and download tracking
- bulk certificate actions such as selected regenerate and selected share
- close-record workflow improvements
