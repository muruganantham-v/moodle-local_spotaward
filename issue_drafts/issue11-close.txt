Implemented an admin audit log viewer for Spot Award.

What was added:
- New `audit.php` page for admin/settings users to review status-track history.
- New API methods to fetch and count audit rows with server-side filters and pagination.
- Filters for date range, actor, nomination ID, from status, and to status.
- Human-readable table output for actor, nomination/course, student, status transition, reason, and timestamp.
- Settings-page link to open the audit log viewer.
- Safe status-label fallback for legacy audit rows.

Verification:
- php -l audit.php
- php -l settings.php
- php -l lang/en/local_spotaward.php
- php -l classes/local/api.php
